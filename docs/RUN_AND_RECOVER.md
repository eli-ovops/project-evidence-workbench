# 运行、停止与恢复

工程：`/Volumes/EXTERNAL/FDE/project-evidence-workbench`。实际 runtime：`/Users/USER/.local/nodejs/node-v22.16.0-darwin-arm64/bin/node`，Node 22.16.0。已经准备依赖和构建，无须用户自行 build。无模型、账户、云端或发布接入。

## 一次启动

双击项目根的 [启动工作台.command](/Volumes/EXTERNAL/FDE/project-evidence-workbench/启动工作台.command)。等效命令：从项目目录运行 `./启动工作台.command`。首次显式启动初始化三份虚构示例到 `data/demo`，并在 runtime 记初始化标记；之后正常启动不会因数据丢失自动新建空根。若已有实例，请回原窗口；会话过期或浏览器关闭后，可先停止本工具再启动。

启动器只使用既有 runtime 和已构建文件，显示本次实际 loopback URL/数据根，通过本机启动文件完成实例认证。端口每次由 OS 选空闲端口，绑定127.0.0.1；不同实例/恢复副本会话绑定 rootId，不以换端口绕过同根写锁。未开机自启，未注册后台自动化。

## 使用虚构样例

“许可复核”列出精确文件/用途/版本，默认不选择项。选择原清单合法未撤销项，单独勾正文许可，确认人用 `fixture-owner`，逐项写记录。点“检查本项目引用”才读许可范围，结论仍是人工记录，未知维度不会变通过。

“公开文字”有独立字段和用途许可，示例用 fixture-owner 仅证明软件流程，不代表 Eli 或客户许可。保存后核准当前文字与依赖，再生成/下载公开包；文字/证据/许可变更和撤销拒绝新的受影响公开下载，旧副本不能追回。每次冷启动读取能力和公开批准默认关闭，复核后再用。

内部包包含完整工具状态和关系，供隔离恢复；有未准许导出的缓存摘录时拒绝新内部导出。公开包只含白名单 Markdown 与脱敏 manifest。实际下载为 JSON 封套，files 内 base64 是已校摘要文件字节；没有内部状态、媒体或凭据夹入公开包。

## 停止

双击 [停止工作台.command](/Volumes/EXTERNAL/FDE/project-evidence-workbench/停止工作台.command)。只请求 runtime 登记且具有本工具控制身份的实例停止；不杀其他应用/端口。正常停止由持有者释放自己的 writer.lock；崩溃后残留锁不自动删，请核对应PID/根/运行记录，不能为重开擅自覆盖。

## 隔离恢复

导出面板选择本工具 COMPLETED 内部包文件，恢复到新 `data/restore-<时间>`；页面给出准确根和启动命令。使用上述 Node runtime 运行 `scripts/start.mjs restore-<时间>`。不能上传公开包/其他应用包/未来schema/坏摘要或悬空ID来恢复。

恢复保留原包/原根、稳定关系和修订，生成独立 rootId；读取许可、公开批准仅失效历史，不复活。不会合并字段或自动切日常库；采用真实恢复副本属于后续实际业务决定。

## 保护与限额

普通预算24MiB/硬上限32MiB按工作数据根计量，包括状态、历史、上一备份、导出/失败包/inflight；恢复另核容器总量。源码/依赖、测试夹具和永久验收证据不混入业务配额，分别保留。50证据、文本256KiB、摘录4KiB是工程保护假设，非大规模实测支持承诺。达到上限不自动删；安全撤销优先用预留空间，失败立即关闭本会话读取/公开，冷启动不复活旧许可。

缺根、坏状态、根身份不匹配、权限/盘异常停止相关写入。未保存自有文本在仍打开页面可复制/本机下载，不承诺浏览器或设备崩溃零丢失；逃生文本不是证据/恢复包。操作结果不明按修订或 exportId 核是否提交，不盲重交。

维护入口是本项目 STATUS 与验收回执。版本升级、真实数据整理/许可、云同步或P1功能需对应后续授权；当前不承诺7×24维护。防护不覆盖同一OS账号恶意软件、完整磁盘毁坏或未经批准网络数据根。
