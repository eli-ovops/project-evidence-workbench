## 4. 登记、检查与公开失效

四事分开：文件登记、OS可读、准许metadata/content读取、准许公开。登记精确路径和用途后默认仅准许该项metadata检查，不授予正文读取或公开。content grant记录对象/范围/actor/日期，不能由目录、路径存在或JSON导入激活。只接受普通文件，隐藏/秘密/数据库/可执行对象拒绝；云占位不触发下载，二进制只查受控元数据。

核数据根身份、父组件及实际打开fd的类型/身份/范围，拒绝路径穿越、逐组件符号链接、登记后替换或打开对象不符；不凭一次realpath认为永久安全。源文件零写入、不给任意路径下载接口。grant撤销后停止后续打开和包含其摘录的新导出；历史记录/旧包保留并标失效，不把缓存继续当当前可用事实；已锁定但尚未完成的包重新核撤销状态并拒绝提交。

检查限选定精确文件：缺失、拒绝、未挂载、版本/日期缺失、冲突分别记覆盖范围。metadata未变仅为“未观察到元数据变化”，内容一致性仍UNKNOWN。公开前对授权文本核当前字节hash，或由有权人明确确认当前版本/定位并注明未核字节；无授权、超限或无法核当前版本则阻断对应公开项。hash相同不证明成果真伪。

固定暂定阈值：[Assumption] 动态事实7天、职责/公开复核90天，从lastVerifiedAt计，许可截止优先；补录时间不重置复核时间，sourceDate未知不填今天。测试注入now()，不改系统时钟、不暴露业务改时接口。提醒只在打开/检查/导出，不做后台监控或规则编辑器。

公开白名单为 `publicTitle/publicRole/publicOutcome/publicLimits/publicLinks/publicAllowedDates`。publicLinks仅人工许可的HTTPS且无私人主机、内部路径或查询秘密；默认排除内部名、客户身份、locator、Owner联系方式、原始回执、媒体。批准锁textRevision/hash、claim/evidence/rights版本、用途/确认人/截止；文字、依赖、权限或复核有效性任一变化即失效。草稿标签不豁免许可，未许可只留内部。

保存当前JSON、非递归字段差异历史、固定上一完整备份，禁止历史包嵌套。同目录临时写、完整校验、sync及替换确认后才显示成功；旧有效状态和恢复点不能因写失败丢失。初始化为独立显式动作；正常启动缺状态/坏schema/丢盘/根身份不同停止写入，不能悄悄建空状态。

工程防护假设（不是实测支持规模）：最多50证据，文本文件256KiB/摘录4KiB，当前状态1MiB、差异历史4MiB、上一备份1MiB；普通总预算24MiB，硬上限32MiB，计入状态、历史、备份、导出、失败包和inflight，预留8MiB只供撤销/完成状态/故障小记录。达到普通限额拒新大内容，不自动删；安全预留亦失败时明确未持久化、会话内停受影响读取/公开，不伪成功。生效读取能力与公开放行只在本启动会话核准，冷启动默认不激活外部grant/公开批准，历史许可须确认当前范围后再用，避免未落盘撤销在重启后被旧状态覆盖；虚构样例只放行本工具fixture。逃生文本下载不依赖新增服务器文件。

敏感GET、写入、包下载均需启动会话认证；仅loopback，校Host/Origin、限制静态根、纯文本显示，秘密不进URL查询/日志/导出。接口仅按已登记对象ID查，拒任意读路径/执行。防护不包含同OS账号恶意软件、完整盘毁坏、网络数据根。

`producerApp, appVersion, schemaName, schemaVersion, exportId, createdAt, sourceRevisionRefs, files[{relativePath,sha256,bytes}], verificationCoverage, limitations, privacyMode, status`。
时间为带时区ISO8601，包内路径无穿越；公开manifest同样脱敏，引用用不泄身份的ID，无内部locator。跨工具引用固定producer/object/revision/hash/维度，只引用、不自动同步或互导。
